MISSION TRACKS Progression & XP
Basic Training

The Basic Training Bases are designed to be attacked with Units available in the Supply Store or better.

Basic Training Base Rewards: Holdout-style target that awards 200 XP + 4 random Crates that spawn in base that award 200 additional XP per Crate. For the first 4 completions, you receive a Voidhammer, Broadside, and Build Logistics for both. After the 4th completion, you receive XP only.
Incursion Base Set (Sentinel Units Only)

Designed for a Platoon of the newest Unit offered in the current Main Event (Dyad), and only Sentinel Units can be deployed. Contains the Main Event story.

Base I 1,000 XP
Base II (unlocked after Base I) 1,500 XP
Base III (unlocked after Base II) 2,000 XP
Set Completion Bonus Rewards 3,500 XP
Tactical Strike Set

Unlocked after completing all 3 Incursion Bases. Designed for Platoons of the Previous Units (Voidhammer) and IS NOT faction locked. Each base contains a single High Value Target worth an additional 4,000 XP that will attempt to escape if not eliminated in time.

Base I (unlocked after Incursion Set) 2,000 XP
Base II (unlocked after Base I) 2,000 XP
Set Completion Bonus Rewards 4,000 XP
